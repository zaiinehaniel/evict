# Disk Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Disk tab to Evict's popover. It shows free disk space and what can be reclaimed (app junk and the user's own files), with one-click removal and a drill-in screen to pick items one by one.

**Architecture:** A new `DiskMonitor` (`@MainActor @Observable`, owned by `AppDelegate` next to `AppMonitor`) holds the scan results and runs the actions. Scanning is done by stateless `nonisolated` scanners in `Evict/Disk/`, off the main actor, one async function per category. The popover gets a Memory | Disk segmented control. The Disk tab has an overview with two groups of category rows, plus a drill-in screen per category that replaces the whole popover content.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Foundation (`FileManager`, `URLResourceValues`, `Process`), CoreServices `MDItem` for the last-used date, QuickLook's SwiftUI `quickLookPreview`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-20-disk-cleanup-design.md`. Read it first; this plan only adds the decisions the spec leaves open.

## Global Constraints

- macOS 14+, Swift 6 strict concurrency, `@Observable`, XcodeGen (`project.yml`). New files under `Evict/` are picked up by `xcodegen generate`.
- **No tests.** The user opted out of tests and TDD (global CLAUDE.md). Each task is verified by building and by the manual checks it lists.
- Build: `xcodegen generate && xcodebuild -project Evict.xcodeproj -scheme Evict -configuration Debug -derivedDataPath build build 2>&1 | tail -3` must print `** BUILD SUCCEEDED **`.
- Run: `open build/Build/Products/Debug/Evict.app`. Quit any installed Evict first.
- Strings are written in English in code. pt-BR translations go into `Evict/Localizable.xcstrings` (Task 7).
- Commits: short imperative subject in the repo's style ("Show …", "Add …"). **No Co-Authored-By / Claude attribution.**
- Work on branch `feature/disk-cleanup`. It lands via PR, after the user reviews it.
- Never touch anything outside `$HOME`. Never request Full Disk Access.
- Size = `totalFileAllocatedSizeKey` (fall back to `fileAllocatedSizeKey`). Free space = `volumeAvailableCapacityForImportantUsageKey` on `URL.homeDirectory`.
- Match the existing views: 360 pt width, 14 pt horizontal padding, `.callout`/`.caption` fonts, `.secondary` text, `Brand` colors, Reduce Motion guards (`reduceMotion ? nil : .easeOut(duration: 0.15)`).

## Review Focus

1. **A file changes between scan and click** (deleted, replaced by a symlink, or a file replaced by a folder). Removal must skip it and count it as a failure, never remove what's there now. Owner: Task 4, check 4.
2. **Huge home folders** (100k+ files in `~/dev`). The scan must not freeze the popover or the Memory tab, must stream results, and must stop when the popover closes. Owner: Task 2, check 3.
3. **Desktop & Documents in iCloud.** Nothing under them may be listed; `isUbiquitousItem` items and `~/Library/Mobile Documents` are skipped. Owner: Task 2, check 4.
4. **Permission denied** for Downloads, Desktop or Documents. The user should see the "Allow access" row, not an empty group or a spinner that never ends. Owner: Task 2, check 2, and Task 5, check 3.
5. **Docker fails to start, or quits while cleaning.** The row must end with an inline error, never stay stuck on "Starting Docker…". Owner: Task 3, check 3.

### Task 1: Disk models, App junk scanning, `DiskMonitor` skeleton

**Files:**
- Create: `Evict/Disk/DiskModels.swift`, `Evict/Disk/FileSizes.swift`, `Evict/Disk/AppJunkScanner.swift`, `Evict/Disk/CommandLineTool.swift`, `Evict/Disk/DiskMonitor.swift`
- Modify: `Evict/Support/Preferences.swift`, `Evict/EvictApp.swift` (create the monitor; add `--dump-disk`)

**Interfaces (produces):**

```swift
enum DiskGroup: String, Codable { case appJunk, yourFiles }

enum DiskRemoval { case delete, trash, emptyTrash, simctl, docker }

enum DiskCategoryID: String, Codable, CaseIterable, Identifiable {
    // App junk, in display order
    case xcodeBuildData, xcodeDeviceSupport, simulators, packageCaches, appCaches, docker
    // Your files, in display order (also the precedence order)
    case installers, xcodeArchives, oldDownloads, largeFiles, nodeModules, trash
    var id: Self { self }
    var group: DiskGroup
    var removal: DiskRemoval          // appJunk → .delete (simulators → .simctl, docker → .docker); yourFiles → .trash (trash → .emptyTrash)
    var title: LocalizedStringResource // "Xcode build data", "Xcode device support", "iOS Simulators", "Package caches", "App caches", "Docker", "Installers", "Xcode archives", "Old downloads", "Large files", "Stale node_modules", "Trash"
    var systemImage: String            // SF Symbol, the implementer's pick
}

struct DiskItem: Identifiable, Codable, Hashable {
    let id: String        // path; "simctl:<udid>"; "docker:images" / "docker:build-cache"
    let name: String      // display name
    let detail: String?   // "iOS 17.2", "41 files", …
    let path: String?     // nil for simctl/docker items
    let isDirectory: Bool
    let size: UInt64
    let lastUsed: Date?
    var isOpen = false    // cache of a running app
}

struct DiskCategory: Identifiable, Codable {
    let id: DiskCategoryID
    var items: [DiskItem]
    var total: UInt64     // sum of item sizes
}

struct DiskVolume { let available: UInt64; let total: UInt64
    static func current() -> DiskVolume?
    var usedFraction: Double; var isLow: Bool /* available < 10% of total */ }

enum FileSizes {   // nonisolated
    static func allocatedSize(of url: URL) -> UInt64      // recursive for folders, doesn't follow symlinks
    static func newestModification(in url: URL) -> Date?  // recursive for folders
    static func lastUsed(_ url: URL) -> Date?             // max(kMDItemLastUsedDate, contentModificationDate)
}

enum CommandLineTool {   // nonisolated
    /// Runs a tool with no shell, returns stdout. Throws on non-zero exit or timeout.
    static func run(_ executable: URL, _ arguments: [String], timeout: Duration = .seconds(60)) async throws -> Data
}

enum AppJunkScanner {    // nonisolated
    static func scan(_ id: DiskCategoryID, runningBundleIDs: Set<String>) async -> [DiskItem]  // every appJunk case except .docker
}

@MainActor @Observable final class DiskMonitor {
    private(set) var volume: DiskVolume?
    private(set) var categories: [DiskCategoryID: DiskCategory]   // only non-empty ones
    private(set) var isScanning: Bool
    func scan()          // cancels any running scan, then scans every enabled category concurrently; each result is stored as it lands
    func cancelScan()
    func category(_ id: DiskCategoryID) -> DiskCategory?
    func reclaimable(_ group: DiskGroup?) -> UInt64   // sum over selection(in:)
    func selection(in id: DiskCategoryID) -> [DiskItem] // items minus kept minus isOpen (kept arrives in Task 4; until then, minus isOpen)
}
```

`Preferences` gains `diskScanCache: [DiskCategory]` (JSON, like `recentlyEvicted`). `DiskMonitor.init` loads the cache, so the tab never opens empty. Each finished scan writes the cache back.

- [ ] **Step 1: Models and helpers.** Write `DiskModels.swift`, `FileSizes.swift` and `CommandLineTool.swift` per the interfaces above. `lastUsed` reads `kMDItemLastUsedDate` via `MDItemCreateWithURL`/`MDItemCopyAttribute`. `CommandLineTool` uses `Process` with a `Pipe`, and terminates the process on timeout or task cancellation.

- [ ] **Step 2: `AppJunkScanner`.** Use these paths (all under `~`) and rules:
  - `.xcodeBuildData`: each folder in `Library/Developer/Xcode/DerivedData` except `ModuleCache.noindex`. The name drops the trailing `-<hash>` (`Evict-abcd1234` → `Evict`).
  - `.xcodeDeviceSupport`: each folder in `Library/Developer/Xcode/*DeviceSupport/` (iOS, watchOS, tvOS, visionOS). The name is the folder name; detail is the platform.
  - `.simulators`: `/usr/bin/xcrun simctl list devices unavailable -j`. One item per device, id `simctl:<udid>`, name = device name, detail = the runtime prettified (`com.apple.CoreSimulator.SimRuntime.iOS-17-2` → `iOS 17.2`). Size is the allocated size of `Library/Developer/CoreSimulator/Devices/<udid>`. If `xcrun` fails (no Xcode), return `[]`.
  - `.packageCaches`: one item per existing path: Homebrew `Library/Caches/Homebrew`, npm `.npm/_cacache`, pip `Library/Caches/pip`, Yarn `Library/Caches/Yarn`, pnpm `Library/pnpm/store`, CocoaPods `Library/Caches/CocoaPods`, Gradle `.gradle/caches`, SwiftPM `Library/Caches/org.swift.swiftpm`. Name = tool name. (This is a deviation from the spec's `brew --cache`: it's the default path and avoids running brew.)
  - `.appCaches`: each folder in `Library/Caches`, skipping `com.apple.*`, the package-cache folders above, and items < 1 MB. Name = the app's display name when the folder resolves via `NSWorkspace.urlForApplication(withBundleIdentifier:)`, else the folder name. `isOpen = runningBundleIDs.contains(folderName)`.
  - Sizes for the items in a category are computed concurrently (`withTaskGroup`). Check `Task.isCancelled` between items.

- [ ] **Step 3: `DiskMonitor`.** Implement it per the interface. `scan()` refreshes `volume`, collects `NSWorkspace.shared.runningApplications` bundle IDs on the main actor, then runs one child task per appJunk category except `.docker` (Docker arrives in Task 3, Your files in Task 2). Empty results remove the category.

- [ ] **Step 4: Wire it up and add `--dump-disk`.** In `AppDelegate`, create `let diskMonitor = DiskMonitor()` and keep it (it's passed to `StatusItemController` in Task 5). Add a DEBUG `--dump-disk` flag, following `dumpState()`: scan, await completion, print each category and its items (`name  size  detail  [open]`) plus volume free/total, then terminate. Expose `func scanAndWait() async` on `DiskMonitor` for this (DEBUG only).

- [ ] **Step 5: Build and verify.** Build (see Global Constraints), then `build/Build/Products/Debug/Evict.app/Contents/MacOS/Evict --dump-disk`. Expected:
  - free/total match Finder's Get Info on Macintosh HD within ~1 GB
  - DerivedData projects are listed with names without the hash
  - App caches have no `com.apple.*` entries, and running apps' caches show `[open]`
  - it finishes in under ~20 s on this Mac

- [ ] **Step 6: Commit.** `git add Evict project.yml && git commit -m "Scan app junk on disk"`

### Task 2: Your files scanning, exclusions, permission opt-in

**Files:**
- Create: `Evict/Disk/HomeExclusions.swift`, `Evict/Disk/UserFilesScanner.swift`, `Evict/Disk/ProtectedFolder.swift`
- Modify: `Evict/Disk/DiskMonitor.swift`, `Evict/Support/Preferences.swift`

**Interfaces:**
- Consumes: Task 1 models, `FileSizes`.
- Produces:

```swift
enum ProtectedFolder: String, CaseIterable, Codable { case downloads, desktop, documents
    var url: URL
    var title: LocalizedStringResource          // "Downloads", "Desktop", "Documents"
    /// Lists the folder; the first call is what triggers the macOS prompt. False on a permission error.
    nonisolated func hasAccess() -> Bool }

enum HomeExclusions {   // nonisolated
    /// The spec's "Never scanned" rules. `denied` folders are skipped too.
    static func shouldSkip(_ url: URL, _ values: URLResourceValues, denied: Set<ProtectedFolder>) -> Bool
    static let resourceKeys: [URLResourceKey]   // keys shouldSkip needs: isHidden, isPackage, isSymbolicLink, isUbiquitousItem, isDirectory, sizes, dates
}

enum UserFilesScanner {   // nonisolated
    /// One walk of the home folder producing every Your files category except .trash, with precedence applied.
    static func scan(denied: Set<ProtectedFolder>) async -> [DiskCategoryID: [DiskItem]]
    static func scanTrash() async -> DiskCategory?   // nil when ~/.Trash can't be listed (see Step 3)
}

// DiskMonitor additions
var userFilesEnabled: Bool { get }                 // Preferences.diskUserFilesEnabled
private(set) var deniedFolders: [ProtectedFolder]
func enableUserFiles()   // sets the pref, checks each ProtectedFolder.hasAccess() in order (each may prompt), then scan()
```

- [ ] **Step 1: `HomeExclusions`.** Implement the spec's "Never scanned" list exactly:
  - `~/Library` is skipped, except that App junk paths aren't walked by this walker at all.
  - Home-root names with the prefixes `Dropbox`, `Google Drive`, `OneDrive`, `Box`, `iCloud Drive` are skipped.
  - Skip anything that is `isUbiquitousItem`, hidden, a package, or a symlink, plus the denied folders.

- [ ] **Step 2: `UserFilesScanner.scan`.** Use a single `FileManager.enumerator(at: home, includingPropertiesForKeys: HomeExclusions.resourceKeys, options: [.skipsPackageDescendants])`. Call `skipDescendants()` on excluded folders and once a `node_modules` is found. Check `Task.isCancelled` every 500 entries. Rules (90 days = `86_400 * 90`):
  - **installers**: files in Downloads or Desktop (top level) with extension `dmg`/`pkg`/`iso`, or a `zip` whose lowercased name contains `install`, `setup`, `macos`, `-mac`, `darwin`, `universal`, `arm64` or `x64`
  - **xcodeArchives**: `~/Library/Developer/Xcode/Archives/*/*.xcarchive` with creation date older than 90 days (read directly; it's the one Library path this scanner reads). Name is the archive name, detail is the date.
  - **oldDownloads**: top-level Downloads entries where `FileSizes.lastUsed` (for folders, `newestModification(in:)`) is older than 90 days
  - **largeFiles**: regular files with allocated size > 1 GiB (`1 << 30`)
  - **nodeModules**: `node_modules` folders whose parent's newest top-level entry (excluding `node_modules`, one level deep) is older than 60 days. Name is the project folder name, detail is the path relative to `~`.
  - **Precedence:** the earlier category wins. An item whose path is inside an already-listed item's path is dropped.

- [ ] **Step 3: `scanTrash`.** Try `contentsOfDirectory(at: ~/.Trash)`. On success, return one item per entry. On a permission error (expected without Full Disk Access; the terminal also can't list it on this Mac), return `nil`, and the Trash category is hidden. Don't add an AppleScript fallback in v1; note it in the PR description.

- [ ] **Step 4: Wire into `DiskMonitor.scan()`.** When `userFilesEnabled`:
  - compute `deniedFolders` with `hasAccess()` (no prompt after the first time)
  - run `UserFilesScanner.scan(denied:)` and `scanTrash()` alongside the App junk tasks

  When not enabled, never touch a `ProtectedFolder`. The walk still covers the rest of home (for `node_modules` and large files), with all three protected folders passed as denied.

- [ ] **Step 5: Build and verify.** Run `--dump-disk` after setting `defaults write com.hanielcortes.evict diskUserFilesEnabled -bool true`.
  1. Plant `~/Downloads/evict-test-installer.dmg` (`mkfile -n 10m`), with expected output under Installers, and `~/dev/evict-test/node_modules` with the parent touched to 70 days ago (`touch -t`), expected under Stale node_modules. Remove both afterwards.
  2. Deny Downloads (System Settings → Privacy & Security → Files and Folders), then run again: Downloads items are gone and the dump prints `denied: downloads`.
  3. While the dump runs, Activity Monitor shows Evict's main thread idle. The scan finishes in under ~60 s.
  4. With a file > 1 GB in iCloud Drive (or a Desktop synced with iCloud), it is **not** listed.
  5. `defaults delete com.hanielcortes.evict diskUserFilesEnabled`. Run again: no TCC prompt appears, and Downloads/Desktop/Documents are absent.

- [ ] **Step 6: Commit.** `git commit -am "Scan the user's own files, behind a permission opt-in"` (add the new files first).

### Task 3: Docker

**Files:**
- Create: `Evict/Disk/Docker.swift`
- Modify: `Evict/Disk/DiskMonitor.swift`

**Interfaces:**

```swift
enum Docker {   // nonisolated
    static var cli: URL?        // first existing: /usr/local/bin/docker, /opt/homebrew/bin/docker, ~/.docker/bin/docker, /Applications/Docker.app/Contents/Resources/bin/docker
    static var app: URL?        // /Applications/Docker.app or ~/Applications/Docker.app
    static var vmDisk: URL      // ~/Library/Containers/com.docker.docker/Data/vms/0/data/Docker.raw
    static func isRunning() async -> Bool                      // `docker info` succeeds within 5 s
    static func usage() async throws -> [DiskItem]             // `docker system df --format json` → items docker:images, docker:build-cache (their "Reclaimable" bytes)
    static func prune() async throws                           // image prune -a -f --filter until=720h; builder prune -f
    static func start() async throws                           // open -g -a <app>, then poll isRunning every 2 s, timeout 120 s → throws
    static func quit() async                                   // NSRunningApplication for com.docker.docker → terminate()
}

enum DockerState: Equatable {
    case notInstalled
    case stopped(vmSize: UInt64)
    case running
    case working(DockerPhase)      // .starting, .cleaning, .stopping
    case failed(String)
    case cleaned                   // "Cleaned" until the next scan
}

// DiskMonitor additions
private(set) var docker: DockerState
func cleanDocker() async   // the spec's "Open and clean" / clean flow; quits Docker only if this call started it
```

- [ ] **Step 1: Implement `Docker` and `DockerState`.** Parse the size strings from `docker system df` (`"2.3GB (45%)"`) into bytes, with decimal units as Docker prints them.
- [ ] **Step 2: Scan.**
  - Not installed (no `app` and no `cli`): `.notInstalled`, and the category is absent.
  - Running: `.running`, and the `.docker` category gets the two `usage()` items.
  - Installed but not running: `.stopped(vmSize: allocatedSize(vmDisk))` with no category items, so it isn't counted in reclaimable.
- [ ] **Step 3: `cleanDocker()`.** If stopped: `.working(.starting)`, then `start()`. Then `.working(.cleaning)` and `prune()`. If this call started Docker: `.working(.stopping)`, then `quit()`. Any throw → `.failed(<localized message>)`. Success → `.cleaned`.
- [ ] **Step 4: Build and verify** with `--dump-disk` (it prints the Docker state) in three states:
  1. Docker running: two items with sizes.
  2. Docker quit: `stopped` with the VM size.
  3. A debug call to `cleanDocker()` with Docker quit: Docker starts hidden, cleans, and quits. With Docker quit mid-start, the state ends as `failed(…)` in ≤ 120 s.

  If Docker isn't installed on this Mac, verify only `notInstalled`, and say so in the task report.
- [ ] **Step 5: Commit.** `git commit -m "Clean Docker images and build cache, starting Docker if needed"`

### Task 6: Category drill-in screen

**Files:**
- Create: `Evict/Views/Disk/DiskCategoryDetail.swift`

**Interfaces:**

- [ ] **Step 1: Layout.**
  - When `openCategory != nil`, `PopoverView` shows only `DiskCategoryDetail`, without the header, tabs or footer. Use a push transition (`.move(edge: .trailing)`), or opacity under Reduce Motion.
  - Top bar: "‹ Disk" button (Esc also goes back), category title, total size.
  - Under it: a "Select all (N)" checkbox and a sort `Menu` (Size, the default, or Age).
  - Rows: checkbox, name, age caption (`Format`-style relative age, e.g. "8 months"), size. Open caches show an "Open" caption.
  - Footer: the primary button "Move N to Trash · X GB" / "Delete N · X GB", following the row's removal-title rules (⌥ flips Trash to Delete), plus a "⌥ deletes permanently" caption for `.trash` categories. The button is disabled when nothing is checked.
- [ ] **Step 2: Behavior.**
  - On appear, the screen snapshots `category.items` into `@State`.
